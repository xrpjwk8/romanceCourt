  • Supabase: 회원 인증, 데이터베이스, 사진 저장, 서버 함수 및 접속·보안 로그 처리를 이용합니다. 현재 프로젝트의 주 데이터베이스 지역은 호주 시드니(ap-southeast-2)입니다. Supabase 공식 안내상 주 처리자는 Supabase Pte. Ltd.(싱가포르)이나 실제 계약 경로의 확인이 필요합니다. 로그·지원·CDN 등은 선택한 DB 지역 밖에서도 처리될 수 있어 호주만을 전체 처리 국가로 안내하지 않습니다.
  • Apple·Kakao: 이용자가 선택한 계정으로 로그인하고, 로그인 식별정보를 전달받거나 연결 해제를 처리합니다. 각 제공자의 자체 계정 처리는 해당 제공자의 방침이 적용됩니다. 알림을 허용한 경우 Apple 푸시 알림 서비스(APNs)로 기기 토큰과 고정 안내 문구를 보내 알림을 전달합니다.
  • Google Cloud: Apple 구매 검증을 위해 Supabase → Cloud Run → Apple 서버 경로를 사용합니다. 서명된 거래·갱신·알림, Apple 거래 식별자와 payload의 앱 계정 연결용 임의 토큰을 일시 처리합니다. 진술·증거 사진·프로필·앱 로그인 JWT는 보내지 않으며 구매 원문을 DB·디스크에 저장하지 않습니다. 실행·키·이미지는 서울(asia-northeast3)에 있지만 기본 로그는 global이므로 전체 처리를 국내 한정으로 표현하지 않습니다. 계약 주체·지원/감사 처리 지역 및 국외 이전 세부 고지는 최종 확인 대상입니다.
  • PortOne·NHN KCP: 별도 동의를 받아 휴대폰 성인 본인확인을 처리합니다. 인증 업체가 받는 정보와 보관 기준은 인증 화면의 고지·동의를 따르며, 연애법정 서버에 저장하는 범위는 아래와 같이 제한합니다.
  • GitHub Pages: 이 안내 웹사이트를 제공합니다. 사이트에 별도 광고·분석 추적 스크립트나 문의 입력 폼을 설치하지 않았습니다. 호스팅 제공자의 접속 정보 처리는 GitHub 개인정보처리방침을 참고해 주세요.
  • 고객지원 이메일: 공개된 네이버 이메일 창구로 문의를 받습니다. 이용자의 이메일 서비스에서 발송되어 담당자 메일함에서 처리되며 문의를 보내지 않으면 이 경로로 정보를 수집하지 않습니다.

국외 이전 고지에는 이전받는 자와 연락처, 국가, 이전 항목·목적·시기·방법, 보유 기간, 적용 근거 및 거부 방법·영향을 구체적으로 명시할 예정입니다. 현재 이 항목은 최종 확인 중이며, 단순히 이 페이지를 게시하는 것으로 필요한 고지나 동의 절차를 대신하지 않습니다.

7. 성인 본인확인

만 19세 이상 회원을 대상으로 별도 동의 후 PortOne·NHN KCP의 실제 휴대폰 본인확인을 사용합니다. 연애법정 서버는 인증 결과를 직접 조회하여 암호화한 생년월일·성별·인증 상태·시각·업체·처리 확인 해시 및 동의 버전·시각을 저장합니다. 앱에는 생년월일 원문을 전달하지 않으며 이름·전화번호·CI·DI·원본 인증 응답을 앱 서비스 DB·로그에 저장하지 않습니다. 인증 업체 자체 수집·보관과 이 범위는 구분합니다. 미성년 결과의 생년월일·성별은 저장하지 않고 미인증·실패를 성공으로 취급하지 않습니다.

본인확인·동의 기록은 탈퇴 시 삭제합니다. 미완료 요청은 만료 후 정기 정리하며 완료 요청의 재사용 방지 확인값은 탈퇴까지 보관합니다. 업체별 계약과 위탁·제공·국외 처리 세부 고지는 정식 출시 전 확정합니다.
