2. 현재 처리하는 정보와 목적

  • 계정과 로그인: 소셜 로그인 식별자와 인증 세션을 회원 식별 및 접근 관리에 사용합니다. Apple·Kakao 로그인을 사용합니다. 로그인 제공자와 인증 서비스가 처리하는 부가 항목은 최종 설정 확인이 필요합니다.

  • 커뮤니티 활동: 사건·상담 글, 진술, 블러 처리된 사진, 투표, 댓글, 공감, 신고·차단 및 운영 처리 기록을 기능 제공과 신고 검토에 사용합니다.

3. 다른 회원에게 보이는 정보

공개한 글·댓글·닉네임·블러 처리 사진과 접근 자격에 따른 사건 결과가 다른 회원에게 표시됩니다. 인증 UID와 신고자 정보는 공개 응답에 포함하지 않습니다. 사진 블러는 이용자가 직접 수행하며 완전한 비식별성을 보장하지 않습니다. 랭킹은 현재 공개 전이며 공개 범위는 제공 전에 안내합니다.

4. 보관과 삭제

회원 정보와 서비스 기록은 이용 중 필요한 범위에서 보관합니다. 탈퇴 시 프로필과 작성한 사건·진술·상담 등 계정에 연결된 삭제 대상 정보를 정리합니다. 사진 저장소와 인증 계정·로그인 연결 정리는 순차 처리하며 실패 시 재시도합니다. 처리 중에는 작업에 필요한 식별자와 사진 경로를 보관합니다.

삭제 완료 후에는 계정 식별자·사진 경로를 제거하고, 재시도 확인용 처리번호·검증값·완료 상태·시각을 완료 후 30일간 보관한 뒤 정리하는 기준을 사용합니다. 마감된 타인 사건의 확정 평균·참여 수는 유지합니다. 신고·운영 이력과 재사용 방지 기록의 별도 보관 기간은 최종 확정이 필요합니다.

Apple 연결 해제용 토큰은 연결 해제 성공 확인 후 삭제하며 실패하면 재시도합니다. 백업의 만료 기간과 복원 후 재삭제 절차는 운영 환경 확인 후 확정합니다. 화면에서 삭제되었다고 모든 백업까지 즉시 소거된 것으로 안내하지 않습니다.

5. 기기에 보관하는 초안

사건·상담 초안은 계정별 각 1개씩 기기에 암호화 저장하며 다른 기기로 동기화하지 않습니다. 블러 완료 사진만 포함합니다. 게시 성공 확인 또는 직접 버리기 전까지 보관하고 로그아웃해도 유지됩니다. 이 기기에서 탈퇴를 요청하면 초안과 키를 삭제합니다. 다른 기기는 탈퇴 상태를 확인할 때 정리하며 오프라인 기기를 즉시 원격 삭제하지는 않습니다.

6. 외부 서비스와 웹사이트

앱은 Apple·Kakao 로그인 및 Supabase 인증·데이터베이스·사진 저장 서비스를 사용합니다. 본인확인 업체는 연동 준비 중입니다. 각 업체의 계약 주체, 위탁 또는 제공 관계, 실제 처리 항목·보관 기간 및 국외 처리 국가·지역은 최종 확인 후 안내합니다.

이 안내 웹사이트는 GitHub Pages에서 제공됩니다. 사이트에 별도의 광고·분석 추적 스크립트나 문의 입력 폼을 설치하지 않았습니다. 호스팅 제공자의 접속 정보 처리는 GitHub 개인정보처리방침을 참고해 주세요. 이메일 문의는 사용자의 이메일 서비스에서 발송됩니다.
